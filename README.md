# MOVIE-WATCH
🎬 **MOVIE WATCH** é um projeto web de busca e exploração de filmes, com uma interface inspirada no universo cinematográfico.  🚀 Desenvolvido com HTML5, CSS3 e JavaScript, o projeto tem como objetivo aprimorar minhas habilidades em desenvolvimento web e evoluir futuramente com integração de APIs, back-end em Java e banco de dados.
